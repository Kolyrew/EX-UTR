# Data

Основной файл: `expression_utr_summary.csv` — итоговый датасет проекта (12 071 запись, ~18 MB).

Полное описание источников, метода сбора и структуры полей — в [`../docs/DATASET.md`](../docs/DATASET.md).

## Колонки

- `Gene_ID` — внутренний идентификатор
- `gene_symbol` — HGNC-символ гена (используется как ключ split-ов и объединения)
- `UTR5_Sequence` — 5′ нетранслируемый регион (A/C/G/T)
- `UTR3_Sequence` — 3′ нетранслируемый регион (A/C/G/T)
- `tissue` — одна из 10 тканей человека
- `expression_level` — уровень экспрессии белка (log-scale, из ProteomicsDB)

## Скрипты сбора

Селениум-скрейперы UTRdb и ProteomicsDB — в директории `Parsers/` в корне репозитория (сохранены для воспроизводимости и не запускаются в основном пайплайне).
